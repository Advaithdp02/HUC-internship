# HUC-internship

## What Git and GitHub are:
- Git is a tool that helps developers save their code during each change .
- It remembers when the changes are made and what the changes are.
- GitHub is a cloud platform where different people can store their code and work on a project together.
- People can collaborate with each other and merge each code together to get a final result.
## Why They are used:
- it is used so we dont lose our code
- we can revert to old changes if needed
- trying new changes safely
- code can be safely stored online
- many people can work on a single project
- helps improve teamwork flow
## Basic Git WorkFlow:
- Intialize a repository: `git init`
- Add files to staging: `git add .`
- Commit changes:`git commit -m "Intial Commit"`
- Connect To remote directory:`git remote ad origin <url>`
- Push to remote repository:`git push origin main`
## How GitHub helps in team collaboration:
- Branches: different develoeprs can create their own branches in the same project and work on it and merge safely.
- Every one has their own copy of the code.
- Pull request: people can submit changes in the code for review if admin approves it can be merged
- Team contribution of each person can be visibile.
